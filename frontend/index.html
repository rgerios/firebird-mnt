3. Catálogo de Rotinas de Manutenção Firebird & Tuning Linux

ROTINAS_MANUTENCAO.md

Selecione o servidor alvo e dispare rotinas de índices online, diagnóstico de transações (OAT/OIT), Sweep manual, Rebuild completo ou otimizações de kernel/disco Linux.

job_reindex_stats Risco Mínimo

Recalcular Estatísticas de Índices

Executa SET STATISTICS INDEX em todos os índices ativos via isql para otimizar o plano de queries.

Exige Parada? Não (100% Online)
job_check_health Leitura Apenas

Diagnóstico de OAT e Saúde do Banco

Lê o Header Page (gstat -h), calcula o gap Next - OAT e identifica transações presas em MON$TRANSACTIONS.

Exige Parada? Não (Read-Only)
job_clean_sweep Médio (I/O)

Executar Sweep Manual

Dispara gfix -sweep para remover versões obsoletas de registros (*backversions*) e avançar o contador OIT.

Exige Parada? Não (Fora do pico)
job_full_rebuild Risco Alto

Ciclo Backup + Restore Completo

Executa gfix -shut full → gbak -b → gbak -c → gfix -v → gfix -online.

Exige Parada? Sim (Shutdown)
job_linux_patches Leitura / Update

Tuning & Patches do SO Linux

Checa noatime no fstab, vm.swappiness=10, fstrim.timer (SSD), apt-mark hold firebird* e patches.

Exige Parada? Não (Reboot opc.)
